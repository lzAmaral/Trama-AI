# Origem visual e roteiro

História: o Trama organiza projetos e agentes numa interface nativa, com pasta explícita para cada tarefa.

- Paleta de `Sources/TramaApp/TerminalTheme.swift`: fundo #000000, texto #ececf2, secundário #9a9aa8, turquesa #35fddc, borda #23282a.
- Tipografia do sistema macOS, como o aplicativo. Sem download de fontes.
- Capturas: views SwiftUI/AppKit reais via `scripts/render-portfolio-preview.swift`, engine fictício restrito a inspect/list, projetos temporários descartados. Os nomes de agentes, estados e tarefas são exemplos; os provedores não foram iniciados.
- Fonte HTML própria, com contrato determinístico `window.seek`, `DUR`, `MARK`, `ready` usado pela skill motion-designer. Ferramentas dessa skill foram utilizadas para revisão; seu código não é incluído no repositório.
- Não afirmar validação autenticada de todos os provedores, sessão de IA real nas imagens, ausência de vazamentos, prontidão para distribuição ou paridade completa com Octo.

| Tempo | Cena |
| --- | --- |
| 0–6 s | Projetos e agentes em uma área de trabalho; nome Trama |
| 6–13 s | Organização por projeto; captura do quadro |
| 13–20 s | Estados e tarefas; captura de lista |
| 20–27 s | Pasta explícita e tarefa; captura do compositor |
| 27–32 s | SwiftUI + Rust, créditos Octo e SwiftTerm |
| 32–38 s | Prévia funcional em desenvolvimento; link do GitHub |

Formato: 1080 × 1080, 60 fps, sem áudio. Nenhum clique ou execução de tarefa é simulado no vídeo.
